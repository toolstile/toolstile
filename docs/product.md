# Product scope

Toolstile is a self-hosted remote MCP gateway for multiple independent users. Each person owns their MCP connections, devices, agent authorizations, capability grants and activity. Devices are editable browser/device labels, not hardware attestation. Installation operators control invitations, suspension and instance administration without dashboard access to other users’ secrets or activity.

An agent has one gateway endpoint aggregating only its permitted remote MCPs. Grant each agent independently. Full access includes current and future tools, resources and prompts; granular grants include only named capabilities. Any explicit block wins during both discovery and execution. Tool description/schema changes preserve name-based grants. Revocation and expiry must be checked live, including cached invocation.

Connect an agent groups agent apps by where they run (a computer, a chat app or an automation), shows each app's steps, waits for the new agent to sign in and then opens its access. Copy the command for an agent app and approve browser OAuth consent; Toolstile automatically creates an agent and a device with detected editable names. The browser remembers its device using an opaque HttpOnly cookie whose hash is stored on the device, so later approvals reuse it. An agent on another machine, such as one reached over SSH, can add `device_name` to its authorization link: the signed request carries it, the consent page names or reuses that device instead of the approving browser's, the browser keeps its own device binding, and a loopback redirect is shown as a one-time `curl` command to run on that machine. Email/password sign-in and browser OAuth for agents and upstream connections are implemented. Advanced headless-script tokens default to 90 days and can use a chosen expiry including never. Do not imply that an upstream credential is an agent credential or a dashboard session.

No managed local subprocesses or laptop connector. Remote HTTP transport compatibility must be verified per protocol/client revision, targeting Claude Code, Codex, Cursor and Claude Desktop. Unsupported interactions are not advertised. Default logging records metadata only; payload debugging is explicit, user-controlled, scoped and time-limited. See [telemetry](telemetry.md) for capture and retention, operator runbooks for recovery, and [verification](verification.md) for remaining compatibility limits.
